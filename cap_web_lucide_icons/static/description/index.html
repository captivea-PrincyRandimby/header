Lucide Icons

A Lucide icon picker inside the Odoo website editor, backed by an extensible inline-SVG sprite.

Overview

Odoo's editor ships Font Awesome icons only. This module brings the modern Lucide icon set into the website builder: pick an icon from a dedicated tab in the media dialog, and it is inserted as a clean inline SVG (.o_lucide_icon) that inherits colour and size from your theme.

Key features

Editor picker tab

A new “Lucide” tab in the media dialog to browse and insert icons, integrated with the website builder.

Inline SVG sprite

Icons are served from a curated, extensible SVG sprite — no external requests, fully themeable via currentColor.

Double-click to replace

Double-click any inline Lucide icon on the page to reopen the picker and swap it.

Theme-friendly

Works with the Captivea icon-ring treatment and button resets out of the box.
