Website Logo per Language

Assign a different website logo for each active language — SVG supported — and serve it automatically on the frontend.

Overview

Multilingual sites often need a localised logo (translated tagline, regional variant). This module adds a per-language logo mapping to the website configuration and swaps the header logo automatically based on the visitor's active language, falling back to the default brand logo when none is set.

Key features

Per-language logos

A dedicated “Logos per language” tab in Settings › Websites to map one logo per language.

SVG support

Upload crisp vector logos (SVG) or raster images.

Helper actions

Buttons to generate rows for all active languages and to reset every entry to the default brand logo.

Automatic frontend swap

The correct logo is rendered in the header for the current language, with a safe default fallback.
