# Captivea Theme — Odoo 19

Website theme for Odoo 19 that automatically applies the Captivea brand identity:
color palette, fonts (Nunito) and CSS presets.

## Architecture (modeled on the official `theme_cobalt` 19.0)
- `__manifest__.py` — theme module declaration (category *Theme/Corporate*, depends on `website`, `configurator_snippets`, `data`).
- `data/generate_primary_template.xml` — generates the theme's primary snippet templates.
- `data/ir_asset.xml` — **declares the SCSS assets** via `ir.asset` records (primary_variables,
  bootstrap_overridden as `prepend`, theme.scss for the frontend).
- `static/src/scss/bootstrap_overridden.scss` — Bootstrap overrides (radius, heading weight).
- `static/src/scss/primary_variables.scss` — `captivea` palette (o-color-1..6), fonts and presets;
  also sets the **default website values** (applied on activation).
- `static/src/scss/theme.scss` — brand gradients, color tints (+30% / +60%) and utility classes
  (`.bg-cap-gradient`, `.o_cap_pill`, `o_cc3` gradient override).
- `views/customizations.xml` — customizations of the `website.*` snippets (classes / `o_ccX` colors).
- `views/images.xml` — theme image library (to be completed).
- `views/new_page_template.xml` — "new page" templates (to be completed).

## Color palette (o-color)
| Odoo variable | Role | HEX |
|---|---|---|
| o-color-1 | Primary red | #BA131A |
| o-color-2 | Light red (secondary) | #E3575D |
| o-color-3 | Pale red | #E29C9F |
| o-color-4 | White | #FFFFFF |
| o-color-5 | Ink (fake black) | #212529 |
| o-color-6 | Light gray (extra) | #F5F4F4 |

Each color also exposes `+30%` / `+60%` tints as CSS variables `--o-color-N-30` / `--o-color-N-60`
(generated by a mixin using `color-mix`, so they follow the palette dynamically).

## Installation
1. Copy the `cap_web_captivea_theme/` folder into your Odoo 19 *addons* path (or import the `.zip` via **Apps > Import Module**).
2. **Apps** → *Update Apps List*.
3. **Website Builder** → **Settings → Pick a Theme** → activate **Captivea Theme**.
   The palette, fonts and presets are applied automatically.
