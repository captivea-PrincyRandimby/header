Website Quotes / Testimonials

Manage customer testimonials from the back-office and showcase them in an infinite, filterable carousel on the website.

Overview

This module adds a Testimonials content type (Website › Content) and a dynamic website snippet to display them. Quotes are stored as records with author, company, role and tags, and rendered on the frontend as a branded single-line carousel that can be filtered directly in the editor.

Key features

Testimonials back-office

Manage quotes with author, company, role and tags from Website › Content.

Dynamic snippet

Drop the testimonials block and filter results in the editor by company, industry, role and tags.

Infinite carousel

Single-line carousel with true infinite looping (cloned slides), 3 cards on desktop/tablet and 1 on mobile, centre card emphasised.

Gradient card design

Signature “gradient card” look: quote on the brand gradient, overlapping quote glyph, author · company footer and tags.

Autoplay

Gentle autoplay, paused on hover; prev/next controls; graceful centred layout when few testimonials fit.
